Operation Guide · Lab04
Supported circuit
Voltage-divider biased 2N3904 NPN common-emitter amplifier. RE is unbypassed. Cin and Cout provide AC coupling; RL loads the output.
Configure
VCC is in V, resistances in kΩ and coupling capacitors in µF. Sine-source amplitude is mV peak; frequency is Hz. All values must be finite and positive. β and VBE are determined by the external device model, not editable approximations.
Run analyses
Run Simulation performs all three analyses, or select DC (.op), AC (.ac) or transient (.tran) individually. DC finds the operating point. AC sweeps gain and wrapped phase. Transient plots the real input and output over time.
Read overlays
Orange arrows and moving highlights show conventional collector and emitter current direction. The pink voltages and purple Q-point use current DC results. Blue and green traces use the same time window and voltage scale from the actual transient samples, preserving amplitude ratio and phase. The display slows the waveforms for inspection. Wire pulses indicate direction at an illustrative speed.
Read results
IE is calculated from simulated VE / RE. Active Region means VC > VB > VE with positive IC; this is a bias-region check, not independent validation. Hover or focus a Bode/transient chart and use arrow keys to inspect samples. Phase curves intentionally break at ±180° wraps. Source and load voltages are measured relative to ground.
Freshness and validation
Changing circuit inputs marks affected runs stale; source edits affect transient only. Validate checks finite inputs and current solver outputs. Instructor validation and reference benchmarks remain Not run. No automated check substitutes for them.
Save / Export / Reset
Export downloads retained solver data, provenance, inputs and freshness as JSON. Save Project also records overlay preferences; file import is not supported. Reset restores default inputs and overlays without fabricating new runs.
Limitations
Emitter bypass CE is not supported. Other bias modes link to the existing analytical Lab03 calculations, not new SPICE topologies. The external 2N3904 model is not instructor-verified. Run history is memory-only and clears on reload.
