Operation Guide · Lab04
Supported circuit
Voltage-divider biased 2N3904 NPN common-emitter amplifier. Emitter Bypass connects CE across RE. Cin and Cout couple the source and load.
Configure
VCC is in V, resistances in kΩ and capacitances in µF. Choose amplitude and frequency units in the Function Generator. The readouts convert to the selected units while preserving the signal. The external 2N3904 model determines β and VBE.
Run analyses
Run Simulation performs all three analyses, or select DC (.op), AC (.ac) or transient (.tran) individually. DC finds the operating point. AC sweeps gain and wrapped phase. Transient plots the real input and output over time.
Read overlays
The orange arrows follow the sign of the simulated collector and emitter currents. A traveling highlight shows direction at an illustrative speed. The pink voltages and purple Q-point use current DC results. Blue and green traces share a time window and voltage scale from the transient results.
Read results
IE is calculated from simulated VE / RE. The active-region check uses VC > VB > VE with positive IC. The Bode marker reads the gain and phase at the generator frequency using the surrounding AC samples. Hover or focus a chart and use the arrow keys to inspect other samples.
Freshness and validation
Changing the circuit or bypass setting marks retained results stale. Source edits make the transient result stale and move the marker on a current Bode curve. The project automatically checks inputs and current results. The reference benchmark applies to the default unbypassed circuit with the documented 2N3904 model.
Save / Export / Reset
Export downloads retained solver data, provenance, inputs and freshness as JSON. Save Project also records overlay preferences; file import is not supported. Reset restores default inputs and overlays without fabricating new runs.
Lab03 and run history
The other bias modes use Lab03 analytical DC calculations. Run history stays in memory until the page reloads.
